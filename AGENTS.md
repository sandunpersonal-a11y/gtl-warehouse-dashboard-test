# GTL Warehouse Dashboard project instructions

These instructions apply to all future updates within this project.

1. Make only the specific changes the user requests.
2. Preserve all existing designs, KPI cards, colours, layouts, charts, filters and functionality unless the user explicitly requests a change.
3. Automatically save and validate all completed changes.
4. Make the changes available for the user to review in Live Preview before requesting approval.
5. Automatically generate a descriptive Git commit message for the completed changes.
6. Request the user's final approval before committing or pushing to GitHub.
7. Once the user approves, automatically commit only the approved changes and push them to the GitHub `main` branch.
8. Never push without the user's explicit approval.
9. Never modify unrelated files, database settings or credentials. Never commit credentials, secrets or unrelated files.
10. Report whether the GitHub push and GitHub Pages deployment succeeded. Include any errors or deployment status that could not be verified.
